Unit 1: Numerical Solutions of Non-Linear Equations

Errors and Accuracy Criteria

  • Absolute Error: $E_a = |Approximate Value - True Value|$
  • Relative Error: $E_r = \frac{E_a}{|True Value|}$
  • Percentage Error: $E_p = E_r \times 100$
  • Stopping Conditions: Terminate calculations when successive iterations agree within standard error limit $|x_{n+1} - x_n| < \epsilon$ or $|f(x_n)| < \epsilon$.

1.5 Newton-Raphson Method (Tangent Line Approximation)

Approximates the root of an equation using sequential localized tangent derivatives down until convergence:

$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}, \text{ where } f'(x_n) \neq 0$
Python Implementation for Newton-Raphson
def newton_raphson(f, df, x0, tol=1e-6, max_iter=100):
    x = x0
    for i in range(max_iter):
        fx = f(x)
        dfx = df(x)
        if abs(dfx) < 1e-12: return None
        x_new = x - fx / dfx
        if abs(x_new - x) < tol:
            return x_new
        x = x_new
    return None

1.6 Fixed Point Iteration Method

Rearranges $f(x) = 0$ directly into the structural path map $x = g(x)$. The sequence converges systematically if and only if $|g'(x)| < 1$ within the neighborhood of the targeted calculation root.

Unit 3: Interpolation and Least Square Curve Fitting

3.1 Finite Differences Framework

Calculates data sequences across equispaced step segments using specific forwarding, backward, and divided operators:

  • Forward Operator ($\Delta$): $\Delta y_i = y_{i+1} - y_i$
  • Backward Operator ($\nabla$): $\nabla y_i = y_i - y_{i-1}$
  • Divided Difference Table (Unequal Spacing): Used to calculate coefficients without re-running parameters when adding new data points.

3.2 Cubic Spline Curve Fitting

Ensures a completely continuous smooth fit across all coordinate transformations. Under natural boundary parameters, outermost limits are fixed to straight paths:

Natural Spline Boundary Conditions: $K_0 = 0, K_n = 0$

3.3 Least Square Regression Ingestion

Minimizes deviation error blocks by solving linear equations systematically ($y = a + bx$):

$b = \frac{n \sum x_i y_i - \sum x_i \sum y_i}{n \sum x_i^2 - (\sum x_i)^2}$
$a = \frac{\sum y_i - b \sum x_i}{n}$

Unit 5: Numerical Solution of Ordinary Differential Equations

5.1 Initial Value Problems (IVP)

Euler's Method (1st Order RK-Method): Updates steps sequentially using the local tangent gradient path ($y_{new} = y + h \cdot f(x,y)$). Requires small step sizes ($h$) to minimize error divergence.

Runge-Kutta Fourth Order Method (RK4 Classical): Provides exceptionally high accuracy tracking using four specific weighted slope variations across each interval step:

$k_1 = h \cdot f(x_n, y_n)$
$k_2 = h \cdot f\left(x_n + \frac{h}{2}, y_n + \frac{k_1}{2}\right)$
$k_3 = h \cdot f\left(x_n + \frac{h}{2}, y_n + \frac{k_2}{2}\right)$
$k_4 = h \cdot f(x_n + h, y_n + k_3)$
$y_{n+1} = y_n + \frac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)$

5.2 Two-Point Boundary Value Problems (BVP)

  • The Shooting Method: Converts a boundary problem into an initial value problem by guessing the initial slope value ($y'(a) = m$), checking the boundary result at the opposite end, and refining guesses via linear interpolation until the target boundary is met.
  • Finite Difference Method: Replaces continuous analytical derivative equations with discrete central finite difference variations to solve problems across multi-point mesh matrices.

Unit 6: Solution of Partial Differential Equations (PDEs)

PDE Engineering Classifications

Categorized according to the standard second-order discriminant system ($B^2 - 4AC$):

Elliptic ($B^2-4AC < 0$) Laplace & Poisson Steady-State Models
Parabolic ($B^2-4AC = 0$) 1D Heat Equation Smoothing Diffusion
Hyperbolic ($B^2-4AC > 0$) Time-dependent Wave Equation Travel

6.4.1 1D Heat Equation Solutions

Bendre-Schmidt Explicit Method: Models diffusion over a mesh grid network. To guarantee numerical system convergence and stability, the mesh ratio parameter ($\alpha$) must satisfy the following strict condition:

Stability Condition: $\alpha = \frac{c^2 \cdot \Delta t}{(\Delta x)^2} \le \frac{1}{2}$

Crank-Nicolson Implicit Scheme: An advanced, unconditionally stable method that removes severe time-step constraints by using a tridiagonal equation system across time segments.
