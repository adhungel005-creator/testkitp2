Unit 1: Solution of Non-Linear Equations

Bracketing & Open Methods

Numerical calculations approximate structural limits using precise metric convergence models:

Absolute Error:
$E_a = |Approx - True|$
Relative Error:
$E_r = \frac{E_a}{|True|}$
Percentage Error:
$E_p = E_r \times 100$
🤖 Bisection Method Script Implementation ($c = \frac{a+b}{2}$) 
def bisection(f, a, b, tol=1e-6):
    if f(a) * f(b) > 0:
        return "Root not bracketed."
    while (b - a) / 2.0 > tol:
        c = (a + b) / 2.0
        if f(c) == 0: return c
        elif f(a) * f(c) < 0: b = c
        else: a = c
    return (a + b) / 2.0

Unit 3: Interpolation & Least Square Curve Fitting

Cubic Spline Curve Fitting: Provides a unique, smooth localized interpolation between consecutive endpoints. For equally spaced coordinates, it utilizes the secondary derivative relation:

$K_{i-1} + 4K_i + K_{i+1} = \frac{6}{h^2}(y_{i-1} - 2y_i + y_{i+1})$

Linear Regression Models: Fits experimental coordinates to straight paths ($y = a + bx$) using the least-square normal calculation system:

$\sum y_i = na + b \sum x_i$
$\sum x_i y_i = a \sum x_i + b \sum x_i^2$
